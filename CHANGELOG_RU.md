# История изменений

## 2.1.0 — 2026-09-06

Наставники WCollections, четыре именованных NPC, общие модели/иконки и статусы пути.
Маппинг исключён. [Полные патчноуты и ограничения](docs/CHANGELOG_v2.1.0_RU.md).

## 2.0.0 — 2026-09-05

### Добавлено

- Система Cultivation с подсистемой rogue и командами `.cultivation rogue`.
- Нативные регрессионные проверки КД, ресурсов, удержания комбо-очков и зарядов; 102 проверки исходников/DBC/Lua.
- Готовый комплект для совместимого JestokyCraft: MPQ A/X/Z, серверный бинарник, шесть DBC, SQL, установщик, rollback и исходники модуля.

### Изменено

- Установщик использует Wow-NWQ.exe и фактический серверный DataDir, сохраняет существующий конфиг Cultivation.
- Общий потолок прямых бонусов Ша сохранён на 60%.

### Исправлено

- Шаг сквозь тень: базовый КД 30 секунд у обоих путей; у Небожителя с изученной Подготовкой — 21 секунда до применения. Запрещён выбор себя, сохранена незаметность Небожителя, снимаются только ROOT/SNARE.
- Заголовки и метаданные талантов до изучения согласованы с выбранным путём, изменённые значения выделяются цветом без дублирования штатного текста.
- Удар по почкам Ша: базовые 1–5 секунд перед штатным diminishing returns.
- Умысел: одна нативная аура удержания очков; финализация и восстановление энергии выполняются один раз после каста.
- Кровоизлияние: персональные видимые заряды хранятся в ауре, расходуются при успешном физическом попадании; финишер Небожителя не расходует заряд.
- Танец теней: нативное уменьшение стоимости до первого применения, без двойного вычитания; Гаррота Небожителя включена в уменьшение периодического урона.
- Исправлена ранняя регистрация AuraScript и 42 повреждённые строки PvP DBC с сохранением числовых полей.
- Fresh-install SQL клона Шага сквозь тень включён в генератор и больше не теряется при пересборке.

### Известные ограничения

- Prebuilt предназначен для совместимого JestokyCraft, а не для произвольного AzerothCore: общий бинарник содержит другие модули проекта. Не заменяйте им чужое ядро без сверки матрицы совместимости.
- Крайние сценарии PvP DR, промахов/парирования Кровоизлияния, периодического урона Гарроты в Танце и смены цели/финишера после Умысла не полностью покрыты повторной приёмкой.
- В одном первоначальном нативном прогоне Призрачного удара были три отказа; 14 последующих прошли, причина первого отказа не установлена.
- Пользователь принял сборку в игре; основной сервер прошёл startup с `disabled replacement groups=0`. Это не означает, что непроверенные крайние сценарии автоматически пройдены.

## 2.0.0-candidate2 — не принят

### Исправлено

- Fresh-install SQL теперь создаёт `creature_template` и model rows клона «Шага сквозь тень» (`900406`).
- Внутренний DB-bound script переименован в `npc_cultivation_rogue_shadowstep_clone`; startup больше не должен выдавать `Script named ... is not assigned in the database`.
- Postflight и архитектурный regression требуют точное совпадение C++ registration, fresh SQL и upgrade SQL.

### Известные ограничения

- Кандидат не становится релизом до явного GUI/gameplay acceptance пользователя.

## 2.0.0-candidate1 — не принят

### Изменено

- Система переименована из Rogue Paths в Cultivation.
- Реализация разбойника выделена в подсистему `rogue`.
- Команда `.roguepath <действие>` заменена на `.cultivation rogue <действие>`.
- Loader, конфигурация, ScriptName, таблицы постоянного состояния и SQL переведены в пространство имён Cultivation/Rogue.

### Исправлено

- Миграция переименовывает существующие characters-таблицы без потери выбранного пути и сохранённых кнопок.
- Добавлена regression-проверка, запрещающая возврат старой активной команды и старых имён интеграции.

### Известные ограничения

- Кандидат ещё не прошёл пользовательскую игровую приёмку.
- До приёмки нет тега, GitHub Release и merge в `main`.
