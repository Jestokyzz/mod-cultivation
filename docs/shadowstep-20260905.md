# Shadowstep — кандидат, приёмка ещё не пройдена

Источники отказа: generator задавал 20000/15000 мс, после native -30% получалось 14000; Celestial AfterCast снимал все speed-decrease ауры, включая Stealth; CheckCast исключал себя только у Sha. Предыдущий тест утверждал ошибочные 20000 и проверял только относительные 70%, поэтому пропускал неверную базу.

Контракт: без Preparation -> до первого использования Shadowstep 30000 мс на обоих путях; изучение Preparation Небожителя -> 21000 до следующего каста; сброс -> 30000. Уже идущая перезарядка остаётся прежней. Ша не наследует пассив Preparation Небожителя. Небожитель принимает союзника/противника, но не себя, сохраняет незаметность и штатное ускорение, снимает только root/snare. Ша принимает только противника.

Backup: `F:\JestokyCraft Backups\cultivation\pre-change-shadowstep-20260905\manifest.json` (проверен, 140 файлов). Исходные ошибки воспроизведены `tools/test_shadowstep_contract.py` до исправления. Production клиент подтверждён: `C:\Games\JestokyCraft\Wow-NWQ.exe`.

Релизный manifest, native runtime и GUI acceptance обязательны перед статусом known-good. SQL, EXE клиента, иконки и прочие механики не входят в эту правку.

## Проверено и установлено

- `test_shadowstep_contract.py`: 3 теста; исходное состояние отклонено, исправленное принято.
- `build_data.ps1`: все статические проверки прошли; в дополнение прошли Celestial resources и 258 buff-locales.
- Изолированный сервер: 68/68 native проверок, реальные non-triggered casts, серверная величина до каста, передача клиенту `SMSG_SET_PCT_SPELL_MODIFIER` (-30 и 0), отсутствие post-cast correction.
- Полный schema6 protocol cycle: переключение путей, сохранение кнопок/талантов/КД, relog прошли.
- Основной клиент и сервер получили только Spell.dbc/owner Z и worldserver. `work/shadowstep-20260905/installed-manifest.json` содержит SHA-256 всех трёх целей и rollback; заменённый Z: `8dce3254a9be0b32706af3c00a1cd920c719760cb5750faf78ffffa454043087`.
- GUI tooltip после установки ещё не принят: инструмент Windows computer-use не запустился (`failed to write kernel assets`, os error 3). Пользователь штатно закрыл клиент; основной сервер остановлен SIGINT с проверкой членов консоли, не force-kill.

## Дополнительные находки

1. Старый тест утверждал 20000 мс и проверял только относительные 70%, маскируя неправильную базу. Теперь ожидаемые 30000/21000 заданы независимо.
2. Повторная генерация теряла fresh-install SQL template 900406. Generator теперь воспроизводит точный прежний tail, а build_data проверяет SQL без записи; production SQL не менялся.
3. В исходных клиентских и серверных PvP-записях (вне Cultivation) уже присутствуют 28 неверных string offsets и повреждённые локализации. Этот кандидат сохраняет их байты; их происхождение и восстановление требуют отдельного разбора. Полная DBC schema-валидация из-за этой legacy-проблемы не объявляется пройденной; текущий semantic diff проверяет все записи и допускает изменения только двух Shadowstep IDs, полей 29/30 и описаний.

## Патчноуты

### Добавлено

Независимые fresh-state и native Shadowstep regression-проверки.

### Изменено

Базовый КД обоих путей — 30 сек.; изученная Preparation Небожителя даёт 21 сек.

### Исправлено

Снятие своей незаметности, self-target Небожителя, неверная база cooldown, невоспроизводимый SQL tail сборки.

### Известные ограничения

Требуется GUI-проверка tooltip без Preparation и после её изучения. Найденные legacy PvP string-offset/localization дефекты в этот кандидат не входят. GitHub main/tag/Release не публиковались.
