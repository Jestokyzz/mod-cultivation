# Cultivation 2.1.0 — готовый комплект для совместимого JestokyCraft

Пакет содержит клиентские MPQ, серверный worldserver.exe, восемь DBC, SQL,
исходники, проверки и инструкции. Общие NPC/модели/UI находятся в корне модуля;
классовый код остаётся в src/rogue. Декорации маппинга не входят.

## Совместимость

Только Windows x64, JestokyCraft ruRU build 12340, Wow-NWQ.exe и точный набор
базовых архивов/DLL из package-manifest.json. Это не полный WoW-клиент и не
универсальный worldserver для произвольной сборки AzerothCore. Бинарник интегрированный:
сохраняет зависимости JestokyCraft; не заменять им несогласованный сторонний сервер.
Для другой базы требуется сборка по core-patches/cultivation.patch и прежней
docs/compatibility_matrix.md, отдельное слияние DBC/UI и acceptance.

## Установка

1. Проверить SHA256SUMS и package-manifest; сделать согласованный clone.
2. Закрыть целевые клиент, worldserver/authserver. Проверить доступность F: и место.
3. Запустить installer/Install-Cultivation.ps1 с точными ClientRoot, ServerRoot,
   ServerDataRoot, MySqlExe и именами World/Characters/AuthDatabase. Пароль вводится
   защищённым запросом, конфиги и учётные записи не включены в пакет.
4. Для уже установленного v2.0.0 добавить `-UpgradeFrom200`. Без этого ключа
   применяется fresh SQL. Legacy Rogue Paths сначала мигрируется по v2.0.0 инструкции.
5. Новые NPC IDs должны быть свободны. Установщик не перезаписывает чужие NPC;
   уже настроенный тестовый контур не является fresh install target.
6. Запустить worldserver, проверить disabled replacement groups=0 и четыре NPC;
   затем Wow-NWQ.exe. Тестовый clone — 1920x1080, gxWindow=1, gxMaximize=1.

Интенданты без товаров. Выбор строки в окне наставника ничего не изучает;
«Изучить» выбирает путь через сервер. Таланты не выдаются автоматически.

## Откат

До запуска сервера восстановить файлы по проверенному F backup manifest и SQL
из той же резервной копии. Новые Q/R/S/U удалять только если manifest помечает их
как отсутствовавшие до установки и текущие SHA совпадают с установленными;
сначала сохранить их на F:. Старый rollback-скрипт намеренно останавливается на
новом файле, требуя этого явного решения. Не удалять архивы по одной букве.
SQL world.rollback.sql удаляет только четыре новых NPC; состояние игроков
не откатывать отдельным старым дампом поверх свежих игровых данных.

## Проверки и ограничения

Пользователь одобрил выпуск 2026-09-06 после игровых проверок; маппинг исключён.
Автоматические отчёты перечислены отдельно, они не подменяют ручные проверки.
Редкие lifecycle-сценарии статуса (death/forced restart) не отмечаются как
повторно проверенные в этом выпуске. Материалы моделей адаптированы к Wrath,
пиксельная эквивалентность retail shaders не заявляется.
